# Telemedicine Symptom Checker

A small web app that asks a few medical screening questions and gives a general doctor-style assessment, including possible diagnosis and over-the-counter treatment suggestions.

## Features

- Age, sex, and symptom entry
- Fever, cough, sore throat, nausea, rash, and more
- Symptom duration and severity tracking
- Basic red-flag screening
- Suggested OTC treatment advice
- Safety guidance and urgent-care alerts

## Run locally

From the project folder:

```bash
cd "/Users/tempprofile/Desktop/current date/telemedicine-app"
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Important note

This tool is for educational and informational use only. It does not replace evaluation by a licensed healthcare professional.
